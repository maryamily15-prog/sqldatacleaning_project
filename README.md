E-commerce Sales Data Cleaning Using SQL
About the Project

This is my first data cleaning project as a beginner in data analysis. I worked on an e-commerce sales dataset using SQL Server to clean and improve the quality of the data.

What I Did

In this project, I used SQL to:

Identify and remove duplicate records.
Standardize data for consistency.
Handle missing values.
Correct data types.
Tools Used
SQL Server (T-SQL)
